# Regole per agenti

Seguire `CLAUDE.md` come contratto editoriale comune. Ogni agente lavora su un branch dedicato, modifica i file strutturati, esegue la validazione e descrive nella pull request il comportamento finale e i controlli svolti.

Non versionare media pesanti, segreti, token o cache. Non cambiare il contenuto parlato, i claim o lo stile del brand senza una richiesta esplicita.
