# Skyground — Crescita centri estetici 01

Primo progetto di riferimento del sistema. Il render approvato dura 115,933 secondi.

## Decisioni creative consolidate

- Cinque inserti complessivi da angolazioni alternative.
- Diciotto motion card.
- Captions mostrate solo quando non è attiva una motion graphic esplicativa.
- Nessun header “Skyground AI/01”.
- Brand finale presente soltanto nella CTA.
- Voce originale continua anche durante gli inserti Higgsfield.

## Modifica consigliata

Per cambiare testi o tempi, intervenire prima sui JSON e poi eseguire `studio.py sync`. La modifica diretta di `composition/index.html` è permessa soltanto per layout o animazioni che non sono ancora rappresentate dallo schema.
